# レビュー出力テンプレート

以下の構成に従って出力する。セクションの追加・名称変更はしない。省略は各セクションの注記に従う。

```markdown
# 要件定義書レビュー結果

- レビュー対象: [ファイルパス（複数ある場合はカンマ区切り）]
- レビュー日時: YYYY-MM-DD HH:MM JST
- 対象コミット: [コミットハッシュ（特定できない場合は HEAD）]
- レビュー種別: 全体レビュー / 追記分レビュー

## 指摘サマリ

- HIGH: N件
- MEDIUM: N件
- LOW: N件

## 指摘詳細

### [HIGH-1] 指摘タイトル

- 該当箇所: ファイル名 L行番号（単一ファイルの場合は L行番号 のみ）
- 指摘: 何が問題か
- リスク: 放置した場合の影響
- 改善提案: 具体的な対策（HIGHは必須。選択肢がある場合は案A/案Bで提示）
- 影響範囲: 変更が波及するファイル・章（既存仕様への変更提案の場合のみ）

### [MEDIUM-1] 指摘タイトル

- 該当箇所: ...
- 指摘: ...
- リスク: ...
- 改善提案: ...

### [LOW-1] 指摘タイトル

- 該当箇所: ...
- 指摘: ...
- 改善提案: ...

## 前回指摘の解決状況

（既存レビューがある場合のみ記載。なければセクションごと省略）

- **解決確認**: [前回指摘ID]「指摘タイトル」
  - 根拠: 解決を確認した箇所と内容

## 推奨アクション

1. 最優先のアクション（対応する指摘IDを付記）
2. ...
```

## 注意事項

- 「全体評価」「総評」「総合評価」等のセクションは追加しない
- 重要度ラベルは必ず `HIGH` / `MEDIUM` / `LOW` を使用する（「重大」「対応必須」「対応推奨」等は使用しない）
- 指摘がない重要度レベルはサマリに `0件` と記載する（行自体は省略しない）
